- `electron/` is a standalone desktop UI (`renderer/` HTML/CSS/JS, frameless window, own skeleton, own custom video player); data comes from the active site's `/api/public/desktop/*` (home, category, search, luganda, title, related, play) via IPC `api` in `main.cjs`, cached per path in userData for offline start. It never shows the website except the small account/plans window. Why: user wants its own app, not the website.
- Sign-in: the account window loads the site's /profile; main reads the Firebase user from its IndexedDB, keeps the refresh token in userData, and checks `luo_subscriptions` via Firestore REST with the user's ID token. Play/Download are gated on an active subscription. Why: must use the real Firebase accounts and subscriptions.
- Downloads use Electron's download manager (pause/resume/cancel) saving to Videos/Movie max. Sidebar/tiles use generated 3D icons `renderer/ic-*.png`.
- Windows release = one NSIS setup (`build/installer.nsi`, built with `nix shell nixpkgs#nsis -c makensis` after @electron/packager) with desktop-shortcut + launch checkboxes; uploaded to public R2 and linked from the Install button. Why: user wants a single setup .exe, not a zip.
- Sign-in is an in-app float (Firebase email/password via identitytoolkit REST in main); Google still uses the account window. A wrong PC clock (ERR_CERT_DATE_INVALID) is tolerated only for our own hosts with one gentle notice. Why: user wants app-styled login and no blocking clock errors.
- Plans and mobile-money checkout run in-app: main writes `luo_transactions`/`luo_subscriptions` via Firestore REST with the user's ID token, deposits go through `/api/public/desktop/pay` + `pay-status`. Admin (admin email or `user_roles` admin/staff) gets full access. Why: user wants no website for payments.
- Home shows Luo/Teso uploaded rows (`/uploads/<lang>`, cached 10 min) under the hero; Trending uses MovieBox's real trending list. Website picks desktop vs phone download by user agent, never window width.
- Setup asks for administrator rights and installs to Program Files (per-machine shortcuts, HKLM uninstall). Why: user wants the setup to start with admin access. SmartScreen warning only goes away with a paid code-signing certificate.
- Luo/Teso rows: server caches only non-empty lists and the app never overwrites a saved non-empty list with an empty one. Why: Firestore quota days returned empty rows while the website showed its browser cache.
